# yoga-journey

Study notes and research for yoga certifications and coursework — currently
the M.Sc. Yoga program, alongside earlier YIC and YCB material.

## Layout

- `anatomy/` — anatomy & physiology notes, shared across all courses (topic-first, not course-first)
- `philosophy/` — yoga philosophy notes, shared across all courses
- `practice/` — asanas, sequences, teaching notes, shared across all courses
- `courses/`
  - `msc/` — current M.Sc. Yoga program
    - `class-notes/raw-transcripts/` — raw class notes and reference PDFs as given
    - `class-notes/processed/` — cleaned-up notes not yet promoted into `anatomy/` etc.
    - `question-papers/` — old question papers, used to calibrate note depth/format
  - `yic/`, `ycb/` — earlier certifications (to be populated)
- `assets/shared/` — shared stylesheets/fonts used across topic pages

See `NOTE-FORMAT.md` for the note format used in `anatomy/` (and the reasoning behind it).

## What goes here vs. stays external

Large raw material — audio/video recordings, big scanned PDFs — stays in
Drive/local storage and is *referenced*, not committed. Small text-based
raw material (class notes, question papers, short reference PDFs) is fine
to commit directly, as in `courses/msc/`. Processed, finished notes
(`anatomy/`, `philosophy/`, `practice/`) are what this repo is really for.
